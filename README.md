## About This Project

An editorial-style, motion-heavy personal portfolio built to reflect both technical depth and design sensibility. Combines a bold serif/sans typographic system, asymmetric magazine-style layout, and heavy scroll-driven motion to present my work as an Applied AI Engineer.

Beyond the standard sections, it includes a dedicated **`/journey`** page — a six-phase editorial case study documenting my internship at Bharat Forge in full detail, from robotics foundations through production-grade multi-robot systems.

---

## Features

| Feature | Description |
|---|---|
| 🎨 Editorial design system | Serif + sans typography pairing, asymmetric magazine-style grid |
| ✨ Scroll-triggered animations | Staggered reveals, custom cursor, magnetic hover, eased smooth scroll |
| 🌓 Persistent dark mode | Respects system preference, persists across reloads/routes |
| 📊 Animated stats band | Scroll-triggered count-up for key metrics |
| 🧭 `/journey` case study | 6-phase deep dive into a real robotics/AI internship |
| 📄 Resume download | CTA wired to an actual resume PDF |
| 📋 Copy-to-clipboard email | One-click copy with toast confirmation |
| ⬆️ Back-to-top control | Live scroll-progress ring, available on all routes |
| 📱 Fully responsive | Motion gracefully simplified on mobile |
